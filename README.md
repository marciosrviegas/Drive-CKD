# DRC G4–G5 — PWA pública

Pacote estático pronto para GitHub Pages, Netlify ou Cloudflare Pages.

Ficheiros: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon.svg`.

## GitHub Pages
Criar um repositório, colocar estes ficheiros na raiz e ativar Pages na branch `main` / pasta `/ (root)`.

## Netlify
Fazer deploy da pasta diretamente no Netlify Drop ou ligar o repositório GitHub.

## Cloudflare Pages
Criar um projeto Pages por Git ou Direct Upload; não é necessário build.

O serviço deve disponibilizar o site por HTTPS. Não introduzir dados diretamente identificáveis de doentes.
